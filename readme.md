# Dijkstra tuần tự và song song

Tìm khoảng cách ngắn nhất từ một đỉnh đến các đỉnh còn lại trên đồ thị vô hướng: bản tuần tự, MPI và CUDA (GPU). Các bản đều in kết quả và thời gian thực thi.

## Tài liệu

- [Hướng dẫn cài đặt](INSTALL.md): C++, MPI, CUDA, Python 3 và Matplotlib.
- [Hướng dẫn chạy](RUN.md): biên dịch, chạy từng bản, đo đồ thị thưa/dày và xuất bảng CSV, biểu đồ.
- [Dữ liệu thử nghiệm](data/README.md): các bộ đồ thị và kế hoạch đo.
